# Remix Files

This repository contains all the essential files and components used throughout the **Remix** project. Everything required to understand, configure, and run the project's infrastructure has been organized here.

### Repository Structure

- **`Files/`**: Authenticated DLL and patched game executable.
- **`Remix-Backend/`**: Backend.
- **`Remix-GS/`**: Game server.
- **`Remix-Launcher/`**: Launcher.
- **`Remix-Matchmaker/`**: Matchmaking.
- **`Remix-Redirect/`**: Redirect.
