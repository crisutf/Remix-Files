# Remix Binaries (`Files/`)

This directory contains the essential binary files and libraries required for the client to run and properly communicate with the Remix backend services.

---

### 📦 File Overview

* **[`Starfall.dll`](https://github.com/crisutf/Remix-Files/raw/refs/heads/main/Files/Starfall.dll)**:
  The authenticated dynamic-link library responsible for managing game logic hooks and connecting the client to the backend (currently configured to connect to `http://localhost:5595`).

* **[`Remix.FortniteClient-Win64-Shipping.exe`](https://github.com/crisutf/Remix-Files/raw/refs/heads/main/Files/Remix.FortniteClient-Win64-Shipping.exe)**:
  The patched game client executable configured to load the required modifications and launch the Remix environment.
